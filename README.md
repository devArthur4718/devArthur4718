## 🚀 About Me

I'm a **Senior Android Engineer** with **7+ years** building scalable native apps in **Kotlin** and **Jetpack Compose** across retail, e-commerce, and banking. I care about **Clean Architecture** and shared, reusable modules: solving a problem once, then making sure no other team has to solve it again.

Today I work on the **SAP Concur** mobile app at **Accenture**. Before that, I worked on **MercadoPago** (Mercado Livre), **Mercado Bitcoin** (Bycoders), and **Pernambucanas** (GO K), usually on English-speaking, distributed teams.
